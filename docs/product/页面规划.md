# 主页面
主页面由以下部分组成：
    顶部搜索栏
    主体内容区域
    底部docker容器区域

顶部搜索栏：
    包含搜索框和搜索按钮
    搜索框用于输入搜索内容
    搜索按钮用于触发搜索操作

主体内容区域：
    展示已有旅行项目列表
    每个项目包含项目项目名称、项目描述、项目图片等信息
    点击项目可跳转至项目详情页
    在右下角有圆形按钮，点击后展示“创建项目”弹窗

底部docker容器区域：
    展示已部署的docker容器列表，包含“主页，探索，我的”三个选项
    每个容器包含容器名称、容器状态、容器IP地址等信息
    点击容器可跳转至容器详情页

# 项目详情页
项目详情页由以下部分组成：
    顶部标题：展示项目名称和项目描述
    主体内容区域
    底部docker容器区域

标题：
    第一行展示“目的地 + 一个概括性词语 + 之旅”
    第二行展示一句话描述

主体区域：
    左侧15%为menu，包含“景点、餐饮、交通、住宿、避雷”四个选项：
        每个选项点击后展示对应的旅行模块
    右侧剩余部分为组合区域：
        用户可以将左侧模块拖拽至右侧，并根据“景点+交通+景点+交通+餐饮+交通+景点”等逻辑循环进行组合

底部docker容器区域：
    展示已部署的docker容器列表
    每个容器包含容器名称、容器状态、容器IP地址等信息
    点击容器可跳转至容器详情页
